# Configured running audio inventory target

The user's requested playback policy is real-PCM prefill followed by nominal-rate DMA playback while decoding replenishes the reserve. The existing startup/recovery watermark already implements prefill. Its clock controller nevertheless learns its normal target from the first two healthy seconds, independently of that watermark. This change makes the selected real-PCM policy determine the running target. It is not a demonstrated cure for the prior intermittent starvation.

Let P be the actual backend startup_frames, H its actual dma_half_frames and R its ring capacity. Controller inventory A-D-P already includes ring PCM and unsent decoded PCM, plus estimated compressed work; it excludes the two prepared DMA halves. The configured target is therefore T = startup_frames - 2H, with no second credit for ring or DMA. Require 0 < T <= R and matching initialized frontend/backend geometry. Read existing output statistics during serialized configuration; do not duplicate rate-to-frame rounding or add public API fields.

Resolved startup_buffer_ms > 0 selects this target. Explicit legacy startup_packets keeps the old learned-target behavior. Private controller begin receives an optional seventh argument; UINT32_MAX selects the exact legacy policy. A configured zero/out-of-range target rejects optional clock tracking, leaving audio priming/playback intact and reporting eligible=false. This includes manually selected P=2H, which supplies no unprepared reserve.

Keep two-second healthy learning for packet estimation/filter initialization; the configured target survives recovery/relearning instead of being replaced by a new early mean. Preserve all ACK/retirement, validity, capacity, +/-500 ppm, 10 ppm/s, one-second decision, four-second filter and actuator rules. No playback pause at T, forced underrun, extra allocation, radio command, DMA/IRQ/PLL policy or ASRC is introduced. T is a control setpoint, not a continuously guaranteed PCM minimum or an end-to-end latency guarantee.

Pure controller methods may become constexpr to evaluate their actual arithmetic with the official ARM compiler without executing Windows test binaries. This refactor must preserve legacy behavior. Verify configured targets across rates and recovery, legacy learning, invalid/thin geometry, correction direction/bounds, stale ACK and actual compiled layouts. Full M7 and live evidence remain separate; all previous failures and original timing gates remain.
