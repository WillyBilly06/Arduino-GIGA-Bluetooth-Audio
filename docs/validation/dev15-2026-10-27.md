# Dev.15 validation — experimental candidate

The combined dev.15 production source passed separate official Arduino Mbed GIGA 4.6.0 Cortex-M7 compilations and static link audits for Receiver and VoiceQualification. Each compiled all 191 library translation units and retained seven enabled codec defaults, six decoder operation tables, the project-owned host and the unchanged stock 139-command controller HCD. Both used the default 2 Mbaud controller UART, disabled private observers and separate build caches. The Receiver BIN is 538,996 bytes; VoiceQualification is 531,172 bytes. Both are below the 786,432-byte project cap. Per-function compiler stack records are not a runtime stack watermark or a complete call-chain bound.

Seventeen ARM64 CPU fixtures passed against the combined AAC and voice candidate. They include the earlier voice suites and focused checks for preemption, transient Busy retry, retained terminal errors, input token ownership, failed begin and lifetime exhaustion. Separate finite CPU cases covered receive-byte pacing and HF command admission. These fixtures use fake radio/I2S and single-thread reentry; they do not establish target scheduling, controller routing or phone behavior. The earlier mono HE-AAC memory and portable fixture evidence is recorded under [dev.14](dev14-2026-10-27.md).

No dev.15 voice firmware was flashed or tested on the GIGA. Controller synchronous-audio route and flow, actual phone interoperability, real microphone providers, long calls, physical output, acoustics and latency remain unqualified. Voice is off by default; without a microphone provider its input is silence. Existing long-playback PCM shortages remain unresolved. A compile or finite CPU test is not an audio-continuity fix.

The compiler input subset of source files, examples and library properties is bound to the source used for the combined CPU fixtures. The production-subset manifest SHA-256 is `a1a72445af6405f443c55e30b846df556faae1fe7b28d5e9c19d82a6423dfe68`; sketch and image hashes are recorded in [the machine-readable summary](dev15-2026-10-27.json). Documentation and test-only updates are reconciled against that compiled production subset.
