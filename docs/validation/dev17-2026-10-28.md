# Dev.17 validation - experimental development source

This update fixes a reproduced host scheduling defect. A completed eligible read-only Classic control could wait for transmit/reply capacity and prevent later accepted A2DP media from progressing. The host now copies that pending control into an existing bounded spare Packet buffer before releasing its borrowed receive lease, then admits ordered media through the normal L2CAP and AVDTP path. It adds no per-frame heap allocation or IRQ work. This is a scoped host-stack correction; it has not been flashed or tested with live phone audio.

Older control replies retain FIFO order. Media still requires the current owner, active media CID, verified security and configured/streaming AVDTP state; fragment ownership, genuine host/controller credits and normal reassembly remain enforced. A bounded four-fragment header lookahead does not skip unsafe traffic. Mutating or mixed signaling, SUSPEND, voice/RFCOMM and unrecognized traffic retain their barriers. The pure matched-response predicate admits only current, unexpired complete successes for capabilities, playback status or complete element attributes. Labels, owner/CID, kind and lengths are revalidated on each attempt. Notification/key/error/stale/unmatched responses and AVCTP/vendor continuations remain fenced; response effects are consumed once at their normal FIFO turn.

The exact source revision passed 69 progress/read/barrier CPU cases, 13 matched-controller-response cases and two focused boundary regressions. Boundary checks cover a four-piece media header under genuine receive grants and an active assembly deadline whose wrapped value is zero. Existing expanded-control, scheduling and Classic-combined suites passed 5758, 6256 and 861 checks. Jobs were confirmed quiet and owned fixture processes/files were removed. These fake-wire CPU fixtures exercise the actual protocol/actor source; they do not establish RF delivery, RTOS timing or phone interoperability.

The exported public test sources are checked against those executed private fixtures, preserving assertions and expectations while normalizing includes and main wrappers. All three exported batch ELFs were separately executed: 69/69, 13/13 and 2/2 passed. Eight offline runner-plan checks passed.
