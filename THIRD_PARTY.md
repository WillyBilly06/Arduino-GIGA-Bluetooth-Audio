# Third-party distribution status

The initial public repository is a documentation scaffold. It contains no
third-party decoder implementation, historical host source, controller
firmware, reference audio, generated media header or raw phone capture.

Project-owned contributions covered by LICENSE/NOTICE use Apache-2.0. That
selection does not replace LGPL-2.1-or-later in libfreeaptx, Helix RPSL/RCSL
notices, Sony copyrights or unresolved LHDC provenance. SBC's identified
Apache path and Opus's identified BSD path still require their notices and
applicable modification/provenance checks if included in a future source
snapshot. All vendor source remains outside this scaffold.

The historical Classic host has separate noncommercial/commercial terms and
is not part of the project-owned Apache export. Local HE test media carry
separate restrictions and are not distributed. Source availability, successful
compilation and file hashes do not establish a redistribution grant.

See the [component and fixture audit](docs/validation/public-license-audit.md)
for each allow/hold decision and the primary-source links. No codec patent,
trademark, Bluetooth qualification or product certification grant is asserted
by this document.
