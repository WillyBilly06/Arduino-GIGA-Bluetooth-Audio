These synthetic fixtures were generated by unmodified AOSP LHDC V5 encoder
source at Bluetooth commit `c77db469de80f86660bc053bec4dee0c5d4b947c`
(`android-17.0.0_r1`, `system/audio/codecs/lhdcv5`). The manifest pins every
upstream Git blob, local source hash, generated file and Cargo dependency lock.
The reference ran on Windows x86_64 with the upstream dev optimization profile.

The `.q31` ramps come directly from the upstream
`lhdc_enc_lossy_frequency_overlap` function. The decoder's full float windows
are those ramps rounded to float, with zero and unity sections prescribed by
the encoder's folding geometry. They replace empirically fitted windows.
The upstream ramp routine is Copyright (C) 2025 The Android Open Source
Project, Apache-2.0; the full license is in the project root.

Each rate/depth directory contains 32 stereo frames of deterministic synthetic
PCM and the actual AOSP encoded output at reported 1000 kbps. The fixed test
limits are absolute gain error <=0.1 dB and signal/error ratio >=20 dB, using
the encoder's known sample delay and excluding four startup frames. These are
regression criteria for these stimuli, not general codec fidelity limits.
Quantization is lossy; the input PCM is not a bit-exact decoder output oracle.

The independent encoder/decoder stage comparison matched all 245760 quantized
coefficients, all SNS scale factors and all gain indices across these cases.
An unquantized direct double-precision inverse transform established the output
scale algebra and matching synthesis windows independently of decoder FFT code.
See `docs/validation/lhdc-aosp-synthesis-2026-10-28.md` for the measurements and
remaining limits, including the separate ARM cross-target numerical mismatch.

Run `python tools/test_lhdc_aosp.py --asan --sanitize` with clang/clang++ on PATH.
No phone, GIGA, radio, Rust installation or NumPy is needed for this regression.

To reproduce the encoded fixtures themselves, provide the pinned upstream
source directory to `tools/reproduce_lhdc_aosp_fixtures.py --reference-source
<directory> --output <new-directory-outside-library>`. This verifies all Git
blob IDs and hashes, builds unmodified encoder sources with the retained lock,
and compares all encoded bytes and ramps. It requires Cargo/Rust; the original
reference used rustc 1.97.1 on x86_64-pc-windows-msvc. The AOSP manifest's
`[build] rustflags` entry is ignored by Cargo; no FMA override is assumed.
